
# Banner Grabber

Banner Grabber is a small tool for grabbing banner information from network services.

## Features

- Connects to a host and port
- Reads service banner output when available
- Displays results clearly

## Usage

```bash
python banner_grabber.py <host> <port>
```

Example:

```bash
python banner_grabber.py example.com 80
```

## Notes

- Not every service returns a banner
- Use only on systems you are authorized to test
